请注意看项目是不是搞错数据库了
docker compose exec -T geekai-mysql mysqldump -uroot -pgeekai123456 --default-character-set=utf8mb4 --no-create-db  geekai_plus | docker compose exec -T geekai-mysql mysql -uroot -pgeekai123456 --default-character-set=utf8mb4 geekai_plus

明白了，表结构创建了但数据没有插入进去。需要在服务器上重新导入完整的数据库 SQL 文件，并确保使用 utf8mb4 编码。

  请在服务器上执行以下步骤：                                                                                            
  1. 先确认 SQL 文件在服务器上存在：                                                                                                                                                                             ks
  ls -la /www/dk_project/dk_app/geekai/database/geekai_plus-v4.2.3.sql

  2. 用正确的编码重新导入完整数据（包含表结构+数据）：

  docker compose exec -T geekai-mysql mysql -uroot -pgeekai123456 --default-character-set=utf8mb4 geekai_plus <
  /www/dk_project/dk_app/geekai/database/geekai_plus-v4.2.3.sql

  关键点是 --default-character-set=utf8mb4 和 -T 参数（非交互模式，允许从文件重定向输入）。

  3. 导入完成后重新插入管理员账号（因为 SQL 文件里的 DROP TABLE 会清掉之前手动加的 admin）：

  docker compose exec geekai-mysql mysql -uroot -pgeekai123456 --default-character-set=utf8mb4 -D geekai_plus -e  "INSERT INTO chatgpt_admin_users (id, username, password, salt, status, last_login_at, last_login_ip, created_at,  updated_at) VALUES (1, 'admin', '6d17e80c87d209efb84ca4b2e0824f549d09fac8b2e1cc698de5bb5e1d75dfd0', 'mmrql75o', 1, 0, '', NOW(), NOW());"

  4. 重启 API 服务：

  docker compose restart geekai-api

  5. 验证数据是否正常（中文不乱码）：

  docker compose exec geekai-mysql mysql -uroot -pgeekai123456 --default-character-set=utf8mb4 -D geekai_plus -e
  "SELECT id, name, url FROM chatgpt_menus;"

  如果看到类似这样的输出就说明成功了：

  +----+-----------+-------------+
  | id | name      | url         |
  +----+-----------+-------------+
  |  1 | AI 对话   | /chat       |
  |  5 | MJ 绘画   | /mj         |
  |  6 | SD 绘画   | /sd         |
  ...

  执行完后刷新首页，应该就能看到导航图标了。

  配置 AI 模型的步骤

  1. 添加 API Key：进入 /admin/apikey，添加你的 AI 平台 API Key（如 OpenAI、DeepSeek、Claude 等）
  2. 配置语言模型：进入 /admin/chat/model，添加或启用需要的模型（关联对应的 API Key）
  3. 系统设置：进入 /admin/system，配置系统级参数（如初始算力、注册开关等）

  建议登录后先改掉默认密码。
